NordKiln Scan

A launch-safety check for apps built with Cursor, Claude Code, Replit, Bolt and v0. Most scanners only look at what anonymous visitors can see. We also test what your logged-in users can see.

No spam. One email when the scanner opens, plus an occasional newsletter. Unsubscribe anytime.

What we check

Cross-user data access

With two test accounts we check whether user B can read, change or delete user A's records through your API or database. This is broken access control (IDOR), the leak that sinks apps.

Supabase RLS

Tables without Row Level Security, over-broad policies, and a leaked service_role key.

Firebase rules

Firestore, Realtime Database and Storage rules that allow public or any-user reads.

Exposed API keys

OpenAI, Stripe, AWS and other secrets in your JavaScript bundles, plus open AI proxy endpoints without rate limits.

How it works

1. Paste your URL

Free scan for leaked API keys, open Supabase/Firebase and missing security headers.

2. Add two test users

We log in as user A and user B and check whether B can read, edit or delete A's data.

3. Fix and verify

Plain-English findings, copy-paste fix prompts for Cursor, Claude Code, Replit, Bolt or v0, then a re-scan and a "verified safe to launch" badge.
